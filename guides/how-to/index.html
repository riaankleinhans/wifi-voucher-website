Add selling credit (top-up PIN)

When credit runs low or hits R0, Sell locks (including Free Purchase Reward). Buy a pack on Top up (or from Happy WiFi), then load the 12-digit PIN here. This is not the shop owner PIN.

Load the PIN

  1. On Sell, scroll to the bottom → tap Seller’s Portal.
  2. At the top, under Selling credit, type the 12-digit top-up PIN (shown as groups like 0000-0000-0000).
  3. Tap Add credit. The balance goes up. Credit once loaded does not expire — it only goes down as you sell.
  4. Tap Back to Sell and continue selling.

Void a voucher

Use Void for a test sale, a wrong package, or when you must cut the customer off. Void cannot be undone — internet for that code stops immediately.

Void from Sales

  1. Tap Sales at the bottom of the screen.
  2. Match the slip to the sale in the list (same access code).
  3. Tap Void → confirm Void voucher? The app warns that this cuts off internet immediately and cannot be undone.

Packages — prices and on / off

Unlock shop settings first. At least one paid package must stay enabled.

Change prices & toggles

Under Package prices, edit the rand amount and display name for each paid package. Use the switch to turn a package on or off on the Sell screen. Free Purchase Reward is free — on/off only (price not editable).

Choose Sell by Time or Sell by Data and save sell mode if you change it. Then tap Save packages.

Forgot shop PIN — email reset

  1. At the bottom of Seller’s Portal, open Forgot shop PIN?
  2. Tap Send reset log in PIN. A 6-digit code is emailed to your saved Seller’s email (valid about 15 minutes). It only unlocks shop settings — it does not add selling credit.
  3. Type the code under Reset log-in PIN from email → Use reset PIN.
  4. You must Set your shop PIN (new 4–8 digit PIN) before continuing.
